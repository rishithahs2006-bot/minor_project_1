# 📊 WhatsApp Chat Analysis

A Python-based data analysis project that extracts useful insights from exported WhatsApp chat data. This project processes chat messages, identifies user activity, and visualizes communication patterns using Python and Matplotlib.

---

## 📌 Features

- 📂 Reads exported WhatsApp chat files
- 💬 Counts total messages
- 👤 Finds the most active user
- 📅 Identifies the busiest day
- 🕒 Identifies the busiest hour
- 📈 Displays message count per user
- 🥧 Generates a pie chart showing message distribution
- 📊 Generates a bar chart of user activity
- 📋 Provides a project summary

---

## 🛠️ Technologies Used

- Python 3.x
- NumPy
- Matplotlib
- Datetime Module

## 📥 Dataset

This project uses an exported WhatsApp chat text file.

Example:

```
12/07/24, 10:45 am - John: Hello everyone!
12/07/24, 10:46 am - Alice: Good morning!
```

Export a chat from WhatsApp:

```
WhatsApp → Open Chat → More → Export Chat → Without Media
```

Save the exported file as:

```
hostel_bois.txt
```
